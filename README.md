# Kumukh Parfums

Site for Kumukh Parfums, a niche fragrance house from Istanbul (since 2021).

- `src.html`: page source. Run `python3 tools/build.py` to produce `index.html` (inlines the wordmark).
- `tools/make_art.py`: generates the illustrations in `assets/art/`.
- Store settings (currency, prices, WhatsApp number, shipping text) are at the top of the script in `src.html`.
